# Changelog

## [0.1.0] — 2026-11-01

Первый публичный выпуск.

### Добавлено

- Шлюз на Python (только stdlib): HTTP + WebSocket (RFC 6455) на одном порту,
  UDP-автообнаружение, профили самолётов с JSON-схемой и валидацией.
- Провайдеры телеметрии: `simconnect` (ctypes, строковые датумы `TITLE` и
  `ATC MODEL`), `mock` и автоматический откат `auto`.
- WASM-мост LVAR/RPN через SimConnect Client Data Area (MobiFlight/SimBridge):
  канал запросов, таймауты, переподключение, запись LVAR через RPN.
- Веб-клиент без фреймворков: авиагоризонт, круговые шкалы, табло, тумблеры,
  галетник, вариометр, высотомер, курсоуказатель; три форм-фактора.
- Редактор панелей: drag-and-drop, undo/redo, сетка, копирование раскладки
  между форм-факторами, сохранение на хост.
- Автоопределение борта по названию и модели ATC; ручной выбор закрепляется
  до смены самолёта в симуляторе.
- Быстрое подключение телефона: QR-код (собственный генератор на stdlib) и
  список сетевых адресов.
- Android-клиент: WebView-панель, UDP-обнаружение, проверка целостности.
- Сборщик Android APK в дистрибутиве: настройки приложения (имя, package id,
  версия, адрес шлюза), сборка из веб-страницы `/android.html` и CLI
  `--build-apk`.
- Установщик Windows (NSIS, per-user, без прав администратора), готовый APK и
  исходники Android внутри.
- Комфорт в кокпите: яркость панели в три ступени, режим киоска.
- Профили: Cessna 172S, Cessna 172 Six-Pack, Daher TBM 930, Airbus A320,
  Piper PA-28, LVAR-демо.

### Исправлено

- Медленный или зависший клиент больше не останавливает рассылку телеметрии:
  у каждого соединения своя очередь (8 кадров) и поток-отправитель, старые
  кадры отбрасываются вместо блокировки шины.
- WebSocket закрывается кодом 1002 при нарушении протокола (немаркированные,
  фрагментированные и слишком большие управляющие фреймы).
- Остановка шлюза не ждёт зависшего клиента: close-фрейм отправляется с
  таймаутом, сокет гасится в любом случае.
- POST/PUT всегда вычитывают тело запроса — keep-alive соединение больше не
  ломается после запуска сборки APK.
- Сборщик APK: сторож таймаута срабатывает, даже если Gradle завис и ничего
  не печатает; в имени приложения запрещены управляющие символы.
- Android: гонка при быстром перезапуске поиска хоста больше не гасит новый
  UDP-приёмник.
- Редактор: при ошибке сохранения ревизия откатывается, повторный клик не
  запускает параллельное сохранение.
- Статика: путь с NUL-байтом даёт 404 вместо исключения, HEAD не дублирует
  тело, обрывы соединений клиентом не засоряют лог трейсбеками.

### Безопасность

- Проверка SHA-256 критичных файлов интерфейса при старте и в браузере.
- CSP `default-src 'self'`, запрет внешних ресурсов, allow-list навигации в
  Android WebView.
