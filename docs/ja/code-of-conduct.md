# 行動規範

## 私たちの約束

私たちは、年齢、体格、可視または不可視の障害、民族、性的特徴、性自認と性表現、
経験レベル、教育、社会経済的地位、国籍、外見、人種、宗教、または性的同一性と
性的指向にかかわらず、すべての人にとって嫌がらせのないプロジェクト参加を実現
することを約束します。

## 私たちの基準

ポジティブな雰囲気を作り出す行動の例:

- 敬意と善意のあるコミュニケーション。
- 建設的な批判と、批判の受け入れ。
- 過ちを認め、影響を受けた人々に謝罪すること。
- コミュニティとプロジェクトにとって何が最善かに焦点を当てること。

許容されない行動: 侮辱、トロール、公的または私的な嫌がらせ、許可なく個人情報
を開示すること、不適切な性的発言。

## 責任

メンテナーは、この規範に一致しないコメント、コミット、コード、その他の貢献を
削除、編集、または拒否する権利を有し、決定の理由を伝えます。

## 適用範囲

規範はプロジェクトのすべての空間（issue、PR、ディスカッション）および
プロジェクトの公的な表現において適用されます。

## フィードバック

違反はメンテナーに非公開で報告してください（連絡チャネルについては
`SECURITY.md` を参照）。すべての苦情は機密に扱われます。

## 帰属

この規範は [Contributor Covenant](https://www.contributor-covenant.org/)
バージョン 2.1 から適応されています。
