# 行为准则

## 我们的承诺

我们承诺让参与本项目对所有人都不受骚扰，无论年龄、体型、可见或不可见的残疾、族裔、性征、性别认同和表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教或性认同和取向。

## 我们的标准

有助于营造积极氛围的行为示例：

- 尊重和友善的交流；
- 建设性的批评以及接受批评；
- 承认错误并向受影响的人道歉；
- 关注对社区和项目最有利的事情。

不可接受的行为：侮辱、挑衅、公开或私下骚扰、未经许可披露个人信息、不恰当的性化言论。

## 职责

维护者有权删除、编辑或拒绝不符合本准则的评论、提交、代码和其他贡献，并说明决定原因。

## 适用范围

本准则适用于项目的所有空间（issues、PR、讨论）以及公开代表项目时。

## 反馈

请私下向维护者报告违规行为（联系渠道参见 `SECURITY.md`）。所有投诉都将保密处理。

## 署名
